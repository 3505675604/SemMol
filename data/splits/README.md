# Scaffold split protocol

Generate the current paper splits from the exact raw CSV versions before building
downstream stores. The default definition is standard Bemis-Murcko: all molecules
with an empty Murcko scaffold form one indivisible group. Groups are seed-shuffled
and allocated towards 80/10/10 sample-count targets without labels. Whole scaffold
groups can make the exact ratio infeasible; the saved report records actual counts.

```bash
python scripts/preprocess/build_scaffold_splits.py \
  --raw-root /path/to/moleculenet/raw --output-dir data/splits \
  --datasets bace bbbp clintox tox21 toxcast sider freesolv esol lipophilicity \
  --frac 0.8 0.1 0.1
```

The previously supplied JSONs are preserved in `legacy_modified/`. They used an
acyclic-connectivity extension and count-optimization allocator. They are historical
artifacts, not splits generated by the current paper protocol. No replacement
indices or performance figures have been fabricated from unavailable raw CSVs.

Every method in a controlled benchmark must use the same generated split files,
CSV hashes and inclusion rules. Ten-seed finetuning repeats training; it is not
ten-fold cross-validation. Hyperparameter folds use only the outer training pool.
